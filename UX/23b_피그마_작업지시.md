## 1. 공통 원칙

- 화면은 일반 프레임, 부품만 컴포넌트(UX/19 1-1)
- 화면 안 부품은 전부 인스턴스, 기존 부품 재사용 우선, 새 부품은 3장 목록 15개만
- 값 출처: 기존 화면 섹션 A-01(`/`), G-02, A-02, A-03, A-07, D-01 1440과 360 프레임의 틀을 복제해서 시작(복제 뒤 본문만 바꿈)
- 틀: Identity/System band, Identity/Topbar(행정안전부 상징 Identity/Logo + 공공 깃랩), Navigation/Sidebar(240, 360은 서랍), Body(판 바깥 8, 판 모서리 12, 컨테이너 최대 1200, 좌우 여백 1440 48, 360 16), Identity/Footer
- 변수: 색, 간격, 모서리, 그림자 전부 변수 연결(KRDS 모음과 `layout` 모음), 직접 값 0
- 글자: KRDS 글자 스타일 연결 100%, Pretendard GOV, Light 이하 금지
- 크기: W와 H 짝수, 패딩과 간격과 모서리 4의 배수, 버튼과 아이콘 정중앙(UX/19 3장)
- 어두운 화면이 대표 모드, 밝은 화면은 변수 모드 전환으로 확인만
- 한 번 호출 120초 안, 섹션 하나씩, 단계마다 버전 기록

## 2. 페이지와 배치

### 2-1. 새 페이지

| 순서 | 페이지 이름 | 내용 | 섹션 |
|---|---|---|---|
| 1 | 3차 / Blueprint | 청사진 2장, 자료 흐름 1장 | BP |
| 2 | 3차 / Flows | 화면 지도 2장, 시나리오 흐름도 10장 | IA, Flow |

- 페이지 순서: 기존 Components 페이지 바로 뒤
- 프로토타입 연결과 흐름 시작점: `3차 / Screens F1~F9` 페이지 안(Figma 흐름 시작점은 페이지 단위)

### 2-2. 섹션 안 배치

- 섹션 하나 = 화면 하나, 섹션 이름 `<화면ID> <영어 이름>`(예 `G-02 Search`)
- 섹션 맨 위: `Spec / <화면ID>` 프레임(폭 1920)
- 그 아래 행: 상태 하나가 한 행, 왼쪽 열 1440 프레임, 오른쪽 열 360 프레임(두 열 격자), 열 사이 160, 행 사이 160
- 360 전용 상태(G-02 Filter sheet): 1440 칸 비움
- 행 이름표: 섹션 왼쪽 밖 글자 레이어 `Label / <상태>`, 열 이름표 `Label / 1440`, `Label / 360`, 글자 스타일 연결
- 섹션 안 여백 160, 섹션 사이 320, 페이지 안 섹션 2열 격자(A-01과 G-02 첫 줄, A-02와 A-12 둘째 줄, A-03과 A-07 셋째 줄, D-01 넷째 줄)
- 프레임 크기: 1440 x 내용 높이(최소 900), 360 x 내용 높이(최소 800), 높이 짝수

### 2-3. 프레임 이름 규칙

- 형식: `<화면ID> <영어 이름> / <폭> / <상태>`
- 예: `G-02 Search / 1440 / Task Fallback`
- 상태 이름: 4장 표의 영어 그대로(대소문자, 띄어쓰기 한 글자까지)
- 기존 측정 도구 이름 형식(`화면번호 / 속성=값`)과 다른 형식이라 측정 대상에서 빠짐(측정 대상 편입은 3차 제출 뒤 결정)
- 문서 프레임: `BP-01 Blueprint officer`, `BP-02 Blueprint developer`, `BP-03 Data flow`, `IA-01 Screen map`, `IA-02 Context rules`, `FL-01`~`FL-10`(시나리오 번호와 같음), `Spec / <화면ID>`

## 9. 전수 검사 항목(합격 값 0)

- 변수 미연결 채움, 선, 간격, 모서리 값
- 글자 스타일 미연결 글자

- 알약 모양(모서리가 높이 절반 이상인 단추, 배지, 입력칸)

- 숫자 카드 띠, 같은 크기 카드 나열, 카드 안 카드
