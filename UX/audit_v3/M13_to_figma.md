- R-26 사이드바 help 아이콘 이름: Figma `popover_help` 대 코드 `help`. 같은 KRDS 도움말 아이콘이면 icon_name_map.json에 `popover_help → help` 대응 한 줄로 끝난다. 이름 정답 선택은 결정 필요(M13_to_code.md 3행).
- A-09, G-06, G-07 'Figma에만 tabs'(모집 중/진행 중/마친 협업, 내 프로젝트/별표/최근 본 도구, 안 읽음/전체): 코드 Signed-in이 정적 모드라 로그인 자료를 그리지 못하고 안내 문장만 나온다. 탭 숫자(1, 0, 3)는 자료가 있어야 정할 수 있어 지어내지 않았다. R-27은 role=developer 측정 매핑 문제(M13_to_code.md 2행).
- R-05 diff-area·diff-file y·h·아이콘(60행): 실제 커밋 화면 변경 파일 영역이 지연 로딩이라 이번 실측에서 상자를 얻지 못했다. 실측 확보 뒤 판정.
- R-30 steps y(313 대 686): 덧붙임 화면. 코드는 단계 표시(1·2·3단계) + 현재 단계 + 따라 하기 묶음 순서이고 Figma는 단계 표시 없이 따라 하기 묶음이 바로 온다. 내용 삭제가 걸려 구조 결정 필요.
