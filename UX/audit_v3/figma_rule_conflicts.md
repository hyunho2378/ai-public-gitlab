# Figma 규칙 충돌 목록(2026. 11. 13.)

대상은 Components / Product의 자체 노드(아이콘, 인스턴스 안쪽, Archive 제외) 약 6,900개다. 규칙 출처는 UX/19 8단계의 합격 값(UX/18 F-01, F-02, F-06, J-07)이다. 노드 수는 같은 날 Figma에서 다시 센 값이며 같은 노드가 여러 항목에 겹친다.

주의: 노드 수와 현재 값 분포는 Figma에서 직접 센 값이다. '코드값 또는 KRDS 토큰' 열의 이유는 노드 이름과 크기에서 추정한 것이라 코드 CSS와 대조한 값이 아니다. 결정 전에 해당 행의 코드 값을 확인해야 한다.

## 정리

- 코드 DOM 값과 KRDS 토큰이 이유인 항목이 대부분이다. 규칙 쪽을 고치는 편이 안전한 것은 글자 크기(15, 13, 17, 19)와 RECTANGLE(달력 칸, 막대, 눈금선) 두 가지다.
- 지금 바로 정리할 수 있는 것은 gap 3, 5(4개)와 radius 1, 5(74개)뿐이다. 코드 쪽 값을 확인하는 대로 처리한다.
- 사용자 결정이 필요한 항목은 패딩 4배수(코드 값 기준 예외), 글자 크기 규칙의 KRDS 기준 변경, RECTANGLE 예외 추가 세 가지다.
