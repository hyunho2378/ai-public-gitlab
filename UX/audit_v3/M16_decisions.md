# M16 판정 (코드 담당, 행 단위)

- 형식: M15_decisions.md와 같은 6열 `화면 | 요소 | 분류 | 항목 | 판정 | 근거`. 폭·인증 한정은 화면 칸에 괄호로(예: R-25(360), R-07(768·1024·1440·1920·Signed-in)). 괄호가 없으면 모든 폭·인증. 측정 담당은 화면·요소(#번호 포함)·분류·항목이 모두 같은 원장 행에 붙인다
- M15_decisions.md 행 단위 표는 그대로 유효하다. 아래 '이어받기 정정'은 M-16에서 원인 단위 근사 연결로 '코드'가 된 행을 정확한 요소 이름으로 다시 적은 것
- 코드 커밋: 976b023(gl-diff-bar·diff-tree 이름표), de463f9(필터 칸 보조색). code_plan/icon_name_map.json에 `icon-file/{git,markdown,json,nodejs}` → `file/*` 4줄 추가(이 파일은 저장소 미추적 상태라 커밋하지 않고 작업 트리에서만 바꿈. 측정은 같은 작업 트리를 쓴다)
