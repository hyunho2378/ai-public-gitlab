### 0-5. 단순 UI 개선을 넘는 지점

- 서비스 청사진: 두 퍼소나 여정과 터치포인트, 자료 흐름을 한 장에(1장)
- 하나의 자료와 하나의 검색: 웹 목록, 검색, 소개 카드, 업무 도우미, MCP, 현황판이 같은 `cards.min.json`과 같은 `searchCore.js` 사용, 같은 상태 7종(3-0)
- 맥락 유지 체계: 화면을 옮겨도 검색어, 탭, 분야, 목록 위치, 대화가 이어짐(2-3)
- 신뢰 체계: 근거 표식, 자료 기준일, 버전 불일치, 시연 표시, 작성 주체 고지가 모든 표면에서 같은 모양(5장)
- 결정 지원: 결과가 "재사용, 참고, 신규 개발" 결정으로 이어지는 동작(도구 요청, 비슷한 프로젝트, 공개 준비 점검)까지 연결(4장 시나리오)
