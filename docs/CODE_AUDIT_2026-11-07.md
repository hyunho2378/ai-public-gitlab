## 미완료 / 판단 보류

- M7_owner_C.md는 검사 시 존재하지 않아 원장 담당 항목을 처리하지 못했다.
- 코드 data-figma 이름표 기반 대응표를 생성했다. 실제 Figma 컴포넌트 실물 연결은 검증하지 않았다. 미등록 부품을 임의로 일치한다고 표시하지 않는다.
- 정적 검색 매칭은 위반 확정 수가 아니다. 리빌딩 직접 색 207행은 생성 KRDS 팔레트 / 주석 등이 섞이며 px 103행도 미디어 / 주석 등이 섞인다. 해당 분류와 모든 화면의 색 대비/아이콘 소수좌표 전수 판정은 후속 검사가 필요하다.
- 현황판 기존 열지도는 작은 폭에서 내부 가로 스크롤이 있다. 문서 가로 넘침 0과 별개다.
- 리빌딩 기존 다른 CSS의 알약/선/단독 버튼 패턴과 1279/1199/768 등 미디어 기준 전수 정리는 남았다.
- 서버 코드 전수 검수, 중복 패턴 추가 추출, 모든 라우트 회귀는 미완료다.
