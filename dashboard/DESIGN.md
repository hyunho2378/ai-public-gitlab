## 2. 색 규칙 (D-15 연한 채움 금지, KRDS 색상 지침 60-30-10, 강조 5% 이하)

| 쓰임 | 변수 | 값 |
|---|---|---|
| 바탕 | `--krds-color-background-white` | gray-0 |
| 숫자 띠, 표 머리 | `--krds-color-background-gray-subtler` | gray-5 |
| 보는 값(막대), 링크 | `--krds-color-element-primary`, `--krds-color-link-default` | primary-50, primary-60 |
| 미표시, '그 외' 막대 | `--krds-color-element-gray` | gray-50 |
| 막대 바탕 | `--krds-color-element-gray-light` | gray-10 |
| 글자 | `text-bolder`, `text-basic`, `text-subtle` | gray-95, gray-90, gray-70 |
| 선 | `divider-gray-light` | gray-20 |

- 색 이름이 다른 계열은 주색 하나만. 상태 색(초록, 주황, 빨강)은 쓰지 않는다
- KRDS 그래픽 색상(graphic 10~90)은 톤 다운 색이라 쓰지 않는다(사용자 규칙: 채도 낮춘 색 금지)
- KRDS 표 부품의 머리 면(secondary-5, 연한 파랑)은 부품 변수 `--krds-table--data-thead-surface`만 gray-5로 바꾼다

## 3. 화면 구성 (2026. 11. 7. 개정: 큰 숫자 카드, 뭉툭한 막대, 알약 막대 폐기)

근거: Pajamas(GitLab 디자인 시스템) Charts, Single stat, Dashboards / ONS(영국 통계청) 데이터 시각화 지침(막대 축 0부터, 눈금선, 이중 축 피하기, 장식 금지) / GitHub, 공공 GitLab 사용자 프로필 활동 달력

1. 머리글: 행정안전부 로고 / AI 정부 실험실 / 공공 GitLab 바로가기(767 이하 숨김)
2. 화면 머리: 제목, 기준 시각, 새로고침
3. 숫자 한 줄: 전체 / 활성 / 참여 개발자 / 공개 이슈 / 별표를 이름(옅게)과 값(굵게, 15)으로 한 줄. 큰 숫자 카드 없음(GitHub 저장소 숫자 줄 방식)
4. 공개 프로젝트 등록 달력: 52주 x 7일, 칸 12, 0은 회색, 1~4단계 주색 20/40/50/70(공공 GitLab 사용자 활동 달력 방식). 제목에 합계
5. 언어: 순위 목록(이름과 값 한 줄, 아래 4 높이 각진 막대)
6. 최근 7일 막대: KRDS 선형 탭으로 항목 고름, 세로축 0부터, 눈금선, 기준선, 막대 폭 16, 높이 240. 제목 합계 = 보이는 막대 합
7. 분야: 제목 '분야 미표시 487개(64.4%)', 표시된 분야 상위 5개와 '그 외'
8. 최근 생성된 이슈: 한 줄 행(제목, 프로젝트 / 때)
9. 공개 프로젝트 표: 프로젝트(이름 두 줄까지, 설명 한 줄) / 만든 사람 / 분야 / 진행 이슈 / 커밋(값과 얇은 막대) / 별표 / 최근 활동
10. 바닥글: product/footer(Context=Panel)

## 3-1. 글 길이 규칙 (최소 / 이상 / 최대)

| 칸 | 최소 | 이상 | 최대 처리 |
|---|---|---|---|
| 프로젝트 이름 | 1자 | 한 줄 | 두 줄까지 균형 줄바꿈, 넘치면 말줄임 |
| 설명 | 없음(칸 숨김) | 한 줄 | 한 줄 말줄임, 전체는 title |
| 만든 사람 | 2자 | 한 줄 | 한 줄 말줄임, 전체는 title |
| 분야 | 없음(미표시) | 4자 | 한 줄 |
| 이슈 제목 | 1자 | 한 줄 | PC 한 줄 말줄임, 767 이하 두 줄 균형 |
| 순위 이름 | 2자 | 한 줄 | 한 줄 말줄임 |
| 숫자 | 0 | 4자리 | 쉼표 포함 7자리까지 줄바꿈 없음 |

- 제목과 두 줄 글은 고아, 과부 없이(text-wrap balance), 본문은 끝줄 보정(pretty)

## 4. 값

- 콘텐츠 최대 폭 1200, 좌우 24(767 이하 16), 구역 사이 48(40), 두 열 사이 40, 구역 제목과 내용 24
- 모든 값은 `src/styles/dash.tokens.css`의 `--dash-*`가 `--krds-*`를 참조. 화면 CSS에 직접 색과 숫자 없음(1px 선만 예외)
- 미디어 구간 KRDS 공식 1023, 767만

## 5. 실행

```bash
npm run dev            # http://127.0.0.1:5801 (자리가 차면 다음 번호)
npm run snapshot       # 공개 API를 받아 저장 자료 갱신
npm run build
```

`?data=snapshot`을 붙이면 저장 자료만 쓴다(시안 캡처와 피그마 대조 기준).
